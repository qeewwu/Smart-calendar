# Smart Calendar

Плагин для Obsidian: календарь с поддержкой ежедневных, недельных, месячных, квартальных и годовых заметок, автоматическим применением шаблонов и авто-раскладкой ежедневных заметок по папкам месяцев.

## Возможности

- **Пять типов периодических заметок**: день, неделя, месяц, квартал, год — у каждого своя папка, формат имени файла и шаблон.
- **Автоприменение шаблона** из указанного `.md`-файла при создании заметки. Поддерживаемые переменные шаблона:
  - `{{date}}`, `{{date:FORMAT}}`
  - `{{time}}`, `{{time:FORMAT}}`
  - `{{title}}`
  - `{{prev}}`, `{{next}}` — соседняя заметка того же типа
  - `{{yesterday}}`, `{{tomorrow}}`
  - `{{start}}`, `{{end}}` — границы периода
  - `{{week}}`, `{{month}}`, `{{quarter}}`, `{{year}}`
  - `{{date+3d}}`, `{{date-1w}}` — сдвиг на N дней/недель/месяцев/кварталов/лет (`d`/`w`/`M`/`Q`/`y`)
- **Авто-раскладка ежедневных заметок** по папкам вида `September 2026` (всегда на английском). Новые заметки переносятся автоматически, старые — командой «Разложить ежедневные заметки по папкам» с предпросмотром списка переносов.
- **Минималистичный календарь**: только числа дней, без точек-индикаторов количества слов. Заметки с содержимым выделяются жирным (можно отключить).

## Установка (ручная)

```bash
OUT_DIR="/путь/к/хранилищу/.obsidian/plugins/smart-calendar" npm run build
```

Затем включить плагин в Obsidian: **Настройки → Сторонние плагины → Smart Calendar**.

## Разработка

```bash
npm install
npm test    # юнит-тесты periods/template/organizer
npm run build
```
